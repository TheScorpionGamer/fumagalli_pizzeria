**Comandi usati su Git Bash**
- git config user.email: configurare la email con cui pubblicare
- git config user.name: configurare l'username con cui pubblicare
- gh repo create <name> --public --push: per creare la repo su github (come pubblica)
- gh auth login: per autenticare l'account github
- git add <elemento>: per aggiungere le modifiche fatte 
- git commit -m "<commento>": per fare un commit sulla repo
- git push: per pushare le modifiche sulla repo
- gh auth logout: per sloggare l'account da git
